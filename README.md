### 課程教學成果

#### Python 資料工程課程

系統性資料工程訓練，帶領學員建立從資料蒐集到價值提煉的完整工程思維。

| 主題 | 內容 |
|------|------|
| 爬蟲技術 | 突破動態 / 靜態限制與反爬蟲機制，精準萃取目標數據 |
| 資料清洗 | 處理遺失值、型態轉換與欄位標準化，確保資料品質 |
| NLP 情緒分析 | 運用情緒分析或統計指標，提煉隱藏的商業價值 |
| 視覺化呈現 | 將生硬數據轉化為高互動性、易讀的圖表與儀表板 |

## 本地執行

此專案為純靜態網站，無需安裝任何依賴套件。

```bash
# 1. Clone 專案
git clone https://github.com/EduCatCode/<repo-name>.git

# 2. 直接在瀏覽器開啟
open index.html
```

> 注意：直接以 `file://` 協定開啟時，部分瀏覽器（如 Chrome）可能因安全限制導致字型無法載入。建議使用本地伺服器，或直接透過 GitHub Pages 網址瀏覽。
>
> 快速啟動本地伺服器：
> ```bash
> python -m http.server 8080
> # 開啟 http://localhost:8080
> ```
